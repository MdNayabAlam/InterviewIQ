# InterviewIQ 🎯

AI-powered interview preparation platform that helps users practice interviews, improve their answers, and prepare for technical and HR interviews.

## 🚀 Live Demo

https://interview-iq-livid.vercel.app

## ✨ Features

- 🤖 AI-powered interview preparation
- 📝 Interview questions and answers
- 👤 User authentication
- 💳 Credit-based system
- 💰 Razorpay payment integration
- 📊 Interview preparation dashboard
- 🔐 Secure backend authentication
- 📱 Responsive web interface

## 🛠️ Tech Stack

### Frontend
- React
- JavaScript
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Razorpay
